# Logs Directory

This directory contains simulation run logs generated by the orchestrator and baseline runner.

## Log Format

Logs are saved as JSON files with the following structure:

```json
{
  "run_info": {
    "idf": "path/to/model.idf",
    "weather": "path/to/weather.epw",
    "zones": ["West Zone"],
    "llm_model": "qwen2.5:7b-instruct",
    "llm_call_interval_min": 60,
    "timesteps": 144
  },
  "log_entries": [
    {
      "timestamp": "2024-01-01 14:00",
      "sim_time_hours": 14.0,
      "outdoor_temp_c": 5.2,
      "zones": {
        "West Zone": {
          "temperature_c": 22.5,
          "cooling_setpoint_c": 24.0,
          "heating_setpoint_c": 20.0,
          "pmv": 0.15,
          "hvac_power_kw": 2.3
        }
      },
      "llm_called": true,
      "llm_reasoning": "Zone is comfortable with moderate energy use...",
      "tool_calls": [
        {
          "name": "set_cooling_setpoint",
          "arguments": {"zone": "West Zone", "value": 24.5}
        }
      ]
    }
  ]
}
```

## Files

- `ai_controlled_run_YYYYMMDD_HHMMSS.json` - AI control run logs
- `baseline_run_YYYYMMDD_HHMMSS.json` - Baseline (fixed setpoint) run logs
- `eplusout.err` - EnergyPlus error/warning log (check if simulation issues occur)

## Usage

Logs are automatically generated when running simulations. To analyze:

```bash
python src/analyze_results.py --ai logs/ai_controlled_run_XXX.json --baseline logs/baseline_run_XXX.json
```
